# Данные и спецификация

- `plukh_codex_spec.md` — исходное ТЗ и точные правила.
- `levels.json` — канонические раскладки, напрямую импортируемые игрой и тестами.
- `references/plukh-ui-reference.png` — художественный референс; координаты из него не используются.
- `verify_levels.py`, `test_reference_rules.py` — независимая модель правил и проверки на Python.

Проверка из корня проекта: `./scripts/check.sh reference`.

Сгенерированные `verified_solutions.json` и `verification_report.txt` удалены: маршруты воспроизводимы из данных, отчёты не являются исходниками. При необходимости вычислите их внутри контейнера; упоминания этих файлов в исходном ТЗ относятся к первоначальному комплекту.

Приложение находится в `src/`; команды запуска и устройство проекта описаны в корневом README.
